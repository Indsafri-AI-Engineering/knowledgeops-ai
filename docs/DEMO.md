# Fictional demo corpus

The running application loads the clearly synthetic Northstar Works knowledge
corpus from `data/fictional_demo/`. It includes general, HR, IT, and
recruitment examples with access scopes enforced by the same retrieval
pipeline used for uploaded documents. These examples are not real company
policies, procedures, or advice.

The app requires OIDC sign-in. The synthetic corpus is independent of demo
identity accounts and mock connector workflows. See the [root README](../README.md)
for local setup and example queries.
