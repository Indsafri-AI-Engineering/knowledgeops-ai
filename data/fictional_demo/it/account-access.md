# Northstar Works Account Access and Device Troubleshooting

Northstar Works and its systems are fictional. This procedure is for
demonstration only.

## Password or sign-in problem

Use the approved fictional training portal's password-reset process. Check
that you selected the correct training account and are using the expected
sign-in page. Never send a password, recovery code, or verification code to
the service desk.

## Multi-factor authentication

Approve only a sign-in request that you initiated. If an unexpected
multi-factor prompt appears, deny it and report the time and displayed
message to the fictional IT Service Desk. Do not bypass multi-factor
authentication.

## Locked account or device

Stop repeated sign-in attempts if the training account reports that it is
locked. Contact the fictional IT Service Desk with the displayed error
message, excluding passwords and codes. The desk will review the fictional
training account; this guide cannot unlock a real account.
